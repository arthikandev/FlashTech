# n8n production wiring (PresenceIQ)

Production backend: **https://backend-blond-theta-13.vercel.app**

## 1. Import workflows

Import each file from this folder into n8n Cloud (Workflows → Import):

- `crm-fetch.workflow.json`
- `hot-lead-slack.workflow.json`
- `crm-push.workflow.json`
- `churn-email.workflow.json` (optional)

## 2. n8n variables

Copy from `devops/n8n/.variables.local` (generated by `node devops/scripts/apply-secrets.mjs`):

| Variable | Production value |
|----------|------------------|
| `PRESENCEIQ_BACKEND_URL` | `https://backend-blond-theta-13.vercel.app` |
| `N8N_WEBHOOK_SECRET` | Same as backend `N8N_WEBHOOK_SECRET` |
| `SEYLAN_DEMO_ACCOUNT_NUMBER` | `064000012548001` |

## 3. Activate workflows → copy URLs to Vercel

After activating each workflow, paste **Production Webhook URL** into backend Vercel env (or `backend/.env.local` then re-run sync):

```bash
bash devops/scripts/vercel-sync-env.sh backend
cd backend && vercel deploy --prod --yes --scope sarangans-projects-55d6b0e1
```

| Backend env | n8n path |
|-------------|----------|
| `N8N_WEBHOOK_CRM_FETCH` | `/webhook/presenceiq-crm-fetch` |
| `N8N_WEBHOOK_SLACK` | `/webhook/presenceiq-hot-lead` |
| `N8N_WEBHOOK_CRM_PUSH` | `/webhook/presenceiq-crm-push` |
| `N8N_WEBHOOK_CHURN` | `/webhook/presenceiq-churn-email` |

## 4. Verify

```bash
cd backend
PRESENCEIQ_BACKEND_URL=https://backend-blond-theta-13.vercel.app bash ../devops/scripts/test-n8n-flow.sh
npm run verify:full
```
